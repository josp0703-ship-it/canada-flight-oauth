개인정보처리방침

최종 수정일: 2026년 10월 11일

Canada Flight Kakao Alert는 개인 여행 계획을 위해 개발된 비상업적 항공권 특가 알림 프로그램입니다. 본 개인정보처리방침은 프로그램에서 Google 사용자 데이터를 어떻게 이용하고 보호하는지 설명합니다.

1. 개인정보 수집 및 이용 목적

본 프로그램은 Google Flights에서 발송한 항공권 가격 변동 이메일을 확인하고, 설정한 조건에 맞는 항공권 특가 정보를 사용자 본인의 카카오톡으로 전달하기 위해 Gmail API를 사용합니다.

2. 접근하는 Google 사용자 데이터

Gmail 읽기 전용 권한(gmail.readonly)을 사용합니다. 이메일의 발신자, 제목 및 본문을 확인하여 항공권 가격, 여행 날짜, 목적지, 항공사 등의 정보를 분석합니다.

이메일을 전송, 수정하거나 삭제하지 않습니다.

3. 데이터 저장 및 보안

Google OAuth 인증에 사용하는 리프레시 토큰은 암호화하여 비공개 GitHub 저장소에 보관합니다.

처리한 이메일의 식별정보, 항공권 가격 기록, 알림 발송 상태 등을 저장하여 중복 알림을 방지합니다. 인증에 필요한 비밀키는 GitHub Secrets를 통해 관리합니다.

4. 외부 서비스 이용

본 프로그램은 Google Gmail API를 통해 가격 알림 이메일을 확인하며, 카카오톡 API를 이용하여 사용자 본인에게 항공권 특가 알림을 전송합니다.

알림에 필요한 항공권 관련 정보가 카카오톡 메시지 API로 전송될 수 있습니다. Google 사용자 데이터를 광고 목적으로 판매하지 않습니다.

5. 데이터 보관 및 삭제

인증 정보 및 항공권 알림 기록은 프로그램 운영에 필요한 기간 동안 보관합니다.

사용자는 저장된 인증 파일과 항공권 기록을 삭제할 수 있으며, Google 계정 보안 설정에서 앱의 접근 권한을 철회할 수 있습니다.

6. Google API 서비스 사용자 데이터 정책

본 프로그램의 Google API를 통한 사용자 데이터 접근 및 이용은 Google API 서비스 사용자 데이터 정책과 적용 가능한 제한적 사용 요구사항을 준수하는 것을 원칙으로 합니다.

7. 서비스 이용 범위

본 프로그램은 개발자 본인이 사용하는 개인용 자동화 도구입니다. 일반 사용자를 대상으로 한 상업적 서비스나 공개 계정 연동 기능을 제공하지 않습니다.
